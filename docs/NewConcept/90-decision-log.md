# Decision log

Every decision that shapes the concept, newest last. **Nothing is a decision until it is in
this table.**

## Format

- **Id** — `D-<nnn>`, never reused. Legacy `Q<n>` ids are *not* continued here; if a decision
  reuses an old one, it is named under *Legacy source*.
- **Status** — `provisional` (recorded so work continues, but the owner is not convinced; carries a
  named doubt and a trigger for revisiting), `agreed` (owner confirmed) or `locked` (do not
  re-litigate without a new,
  superseding entry that names this one).
- A superseded entry is never deleted. It gets `superseded by D-<nnn>` in its status.

# `docs/uebergabe/` — abgeleitete Blätter für Aussenstehende

Hier liegen **verdichtete Zusammenfassungen** zur Weitergabe an jemanden, der das Projekt nicht
kennt. Sie sind aus [`docs/NewConcept/`](../NewConcept/README.md) abgeleitet.

**Sie sind keine Quelle.** Bei jedem Widerspruch gilt `docs/NewConcept/`. Nichts hier darf als
Beleg zitiert werden, und keine Entscheidung wird hier getroffen — dafür gibt es
[`90-decision-log.md`](../NewConcept/90-decision-log.md).

Sie werden nicht laufend gepflegt. Jedes Blatt nennt seinen Stand; ist der alt, ist das Blatt alt.

| Blatt | Wofür |
|---|---|
| [`konzept-kompakt.md`](konzept-kompakt.md) | Gesamtüberblick für die Entwicklung eines Ereigniskonzepts durch Dritte. Stand 2026-08-31. |
| [`antwort-01-ereignisse.md`](antwort-01-ereignisse.md) | Antwort auf die ersten zwei Rückfragen dazu — `source` und was ein Ereignis über einen Wert trägt. Stand 2026-08-31. |

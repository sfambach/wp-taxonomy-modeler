# `Taxmod\Core\Description` — a page as the core describes it

What lives here: the typed description of a page from the renderer plan §3 ([`docs/pakete/renderer-ereignisse/plan.md`](../../../docs/pakete/renderer-ereignisse/plan.md), D-628, D-629): `PageDescription` → `SectionDescription` → `RowDescription` → `FieldDescription`, `ControlDescription`, `Message`. No markup anywhere; JSON only where the description leaves the process.

Must not depend on: WordPress, or anything that draws. The drawers live at the edge.
